🧮 Numerical Methods Root FinderA sleek, interactive Streamlit web application designed to solve non-linear equations using various numerical root-finding methods. This tool is perfect for students, engineers, and mathematicians who need to visualize convergence, track iterative steps, and calculate roots to a specific decimal precision.✨ FeaturesMultiple Numerical Methods:Bisection MethodFalse-Position (Regula Falsi)Newton-RaphsonSecant MethodFixed-Point IterationDynamic Equation Parsing: Input custom mathematical expressions for $f(x)$ natively in the sidebar.Precision Control: Easily adjust the required decimal places using an intuitive slider, which automatically sets the stopping criterion (e.g., $\vert x_i - x_{i-1} \vert$).Comprehensive Metrics: Instantly view the estimated root, total iterations, function value at the root $\vert f(x_r) \vert$, and the final absolute error.Detailed Iteration Table: Track the algorithm's progress step-by-step (bounds, midpoint, function evaluations) with highlighting for the final converged step.Data Export: Download the iteration history as a CSV file for further analysis.Interactive Tabs: Switch between raw Table data, Graphs, Convergence plots, and Method details.🚀 Installation & SetupPrerequisites:
Ensure you have Python 3.8+ installed on your system.Clone the repository:git clone https://github.com/YourUsername/Numerical-Program.git
cd Numerical-Program
Create a virtual environment (Recommended):python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
Install dependencies:pip install -r requirements.txt
(Make sure your requirements.txt includes streamlit, pandas, and any math/graphing libraries you used like sympy or plotly).Run the application:streamlit run app.py
The app will automatically open in your default web browser at http://localhost:8501.📖 How to UseOpen the Setup menu in the left sidebar.Select a pre-loaded example or manually choose your desired numerical Method.Enter your non-linear equation $f(x) = 0$.Input your initial guesses/interval bounds (e.g., a and b for Bisection).Set your Required decimal places to define the stopping tolerance.The main dashboard will instantly update to display the calculated root, summary metrics, and the full iteration table.🛠️ Technologies UsedStreamlit - The web framework used for the interactive UI.Python 3 - Core logic and numerical computations.Pandas - Data manipulation for the iteration tables.🤝 ContributingContributions, issues, and feature requests are welcome!
