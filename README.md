# 🔢 Numerical Methods Root Finder

**An interactive Streamlit app for solving equations using numerical methods.**

Explore different algorithms, track iterations, and visualize results.

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![Streamlit](https://img.shields.io/badge/Built%20with-Streamlit-FF4B4B?logo=streamlit)

</div>

---

## ✨ Features

- 5 numerical methods: Bisection, False Position, Newton-Raphson, Secant, and Fixed-Point Iteration.
- Enter custom equations and starting values.
- Set the required decimal precision.
- View detailed iteration tables.
- Visualize graphs and convergence.
- Export results as CSV files.

 

## 🚀 Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the application**

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## 🧮 Numerical Methods

| Method | Description |
|---|---|
| Bisection | Divides an interval into two halves |
| False Position | Estimates the root using linear interpolation |
| Newton-Raphson | Uses derivatives to find the root |
| Secant | Uses two previous approximations |
| Fixed-Point | Repeatedly applies a rearranged function |
